# HRMS 审查 Checklist（打印/复制用）

## 安全 🔒

- [ ] 接口需登录的均已鉴权
- [ ] 水平越权：改 URL 中 id 不能访问他人数据
- [ ] 垂直越权：EMPLOYEE 不能调 HR 专属 API
- [ ] SYS_ADMIN 不能看薪资全量
- [ ] 敏感字段加密 + 查看审计
- [ ] 无 SQL 拼接、无硬编码密钥/密码
- [ ] 日志无身份证/银行卡/密码明文

## 稳定 ⚙️

- [ ] 写操作有事务
- [ ] 审批/打卡/算薪可防重复提交
- [ ] 异常映射到附录 K 错误码
- [ ] 列表有分页，pageSize ≤ 100
- [ ] 并发更新有 version 或唯一约束

## 业务 📋

- [ ] 符合 PRD 三条：Admin 薪资 / 手机号申请 / 离职双阶段
- [ ] 入职走 onboarding
- [ ] employee_id 作 FK

## 工程质量 🛠

- [ ] 改动在负责模块内
- [ ] 无无关文件改动
- [ ] 无重复代码/过度设计
- [ ] openapi/系分已同步（如有新 API）
- [ ] DDL 有 Flyway 脚本（如有表变更）

## 前端 🖥

- [ ] 路由与系分一致
- [ ] 401 跳转登录
- [ ] 无 moment（用 dayjs）
- [ ] 敏感字段 FieldGuard
