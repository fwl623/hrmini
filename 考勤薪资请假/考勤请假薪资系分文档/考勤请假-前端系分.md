# 2. 详细设计

## 2.1 前端迭代目标

本次迭代实现考勤管理和请假加班模块的全部前端页面，按用户端分为：

**管理后台（AdminLayout）— 8 个页面：**

- 考勤管理：打卡中心、打卡记录、考勤组配置、法定节假日、月汇总、考勤统计（6 页）
- 请假加班：请假管理、加班管理（2 页）

**员工门户（PortalLayout）— 3 个页面：**
- 我的考勤、我的请假、我的加班

**核心交互模式：** 列表页统一使用 `<ProTable>` 展示，表单使用 `<Modal>` / `<Drawer>`，状态使用标签组件着色，图表使用 `@ant-design/charts`，全局组件全部复用前端总系分封装。

### 2.2.2 我的考勤 — 员工端（门户）

门户页面 `/portal/attendance`，仅 EMPLOYEE 角色可访问，数据范围限制为本人。

##### UI&交互

```
PortalAttendancePage
├── 考勤日历 CalendarHeatmap
│   └── 月度打卡概览，每日用颜色标记状态（正常绿/迟到黄/旷工红等）
├── 今日打卡区
│   ├── 打卡按钮 <PunchButton> — type=in(上班) / type=out(下班)
│   │   └── 点击后调 POST /profile/attendance/punch，加载中禁用
│   └── 当日打卡状态展示
│       └── 后端返回 punchStatus → 渲染对应颜色 <AttendanceStatusTag>
├── 补卡入口
│   ├── 补卡弹窗 PunchFixModal → POST /profile/attendance/punch-fix
│   └── 每月剩余次数显示（≤2次/月，超限禁用）
└── 打卡记录列表 ProTable（分页）
```

##### 前端逻辑

**打卡交互流程：**

```
页面加载
  → GET /profile/attendance/calendar（当月考勤日历，含每日状态）
  → GET /attendance/punch/records?dateFrom=today&dateTo=today（今日打卡记录）
  → 渲染页面

员工点击打卡按钮
  → 按钮 loading（防止重复点击）
  → POST /profile/attendance/punch { type, punchTime?, latitude?, longitude? }
  ├── 成功 → Toast「打卡成功」→ 刷新今日记录 → 按钮置灰「已打卡」
  └── 失败 → Toast 错误原因 → 按钮恢复可用

失败场景处理：
  重复打卡  → Toast「已打卡，请勿重复操作」(Redis 幂等拦截)
  GPS 越界  → Toast「不在打卡有效范围」(错误码 40004)
  未登录    → 跳转登录页(错误码 20001)
  网络超时  → Toast「网络异常，请稍后重试」(错误码 90001)
```

**补卡交互流程：**

```
点击补卡 → 弹窗 PunchFixModal
  → GET /attendance/punch-fix/quota（当月剩余次数）
  → 填写：补卡日期 + 类型 + 时间 + 原因
  → POST /profile/attendance/punch-fix
  ├── 成功 → Toast「补卡申请已提交，等待审批」→ 关闭弹窗 → 刷新列表
  └── 失败
      超限(≤2次/月) → 弹窗提示「每月最多补卡 2 次」(40002)
      月已锁定     → 弹窗提示「当月已锁定，请联系 HR 解锁」(40001)
```

##### 组件与交互

| 组件 | 说明 | 交互规则 | 状态覆盖 |
| --- | --- | --- | --- |
| `<PunchButton>` | 打卡按钮，分 IN/OUT | 点击 → loading(禁用) → 成功则置灰「已打卡」/ 失败恢复 | default / loading / disabled(已打卡) / disabled(非打卡时段) |
| `<AttendanceStatusTag>` | 状态标签 | 后端 punchStatus → 对应颜色 | 正常绿 / 迟到黄 / 早退橙 / 旷工红 / 缺上班紫 / 缺下班蓝 |
| `<PunchFixModal>` | 补卡弹窗 | 打开时请求剩余次数；表单校验日期+类型+时间+原因(≤256字) | 可提交 / 超限禁用 / 锁定月不可操作 |
| `<CalendarHeatmap>` | 考勤日历 | 按月展示，每日颜色映射状态，hover 弹明细 | 月数据加载中 / 加载失败显示空日历 |

##### 状态管理

```typescript
// TanStack Query 缓存 key
const QUERY_KEYS = {
  calendar: ['attendance-calendar'],
  records: ['attendance-records'],
  fixQuota: ['attendance-fix-quota'],
};

// 打卡成功后失效缓存，触发页面刷新
function usePunch() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (data) => POST('/profile/attendance/punch', data),
    onSuccess: () => {
      queryClient.invalidateQueries(['attendance-calendar']);
      queryClient.invalidateQueries(['attendance-records']);
    },
  });
}
```

##### 边界场景

| 场景 | 处理 |
| --- | --- |
| **重复点击** | 前端按钮 loading 禁用 + 后端 Redis 幂等键，双重防重 |
| **网络超时** | 超时重试 1 次，仍失败 Toast 提示，不阻塞下次操作 |
| **GPS 定位失败** | 定位失败传空，后端按无 GPS 处理 |
| **非打卡时段** | 按钮置灰，显示「当前不在打卡时段」|
| **跨天打卡** | 打卡时间取后端服务器时间，前端不传则后端填充 |

##### 所需API

| 接口 | 说明 | 缓存策略 | 响应示例 |
| --- | --- | --- | --- |
| `POST /profile/attendance/punch` | 打卡 | 成功后失效日历+记录缓存 | `{ "code": 0, "data": { "punchStatus": "NORMAL" } }` |
| `GET /profile/attendance/calendar` | 考勤日历 | 切换月份时重新请求 | `{ "code": 0, "data": { "year": 2026, "month": 7, "days": [{ "date": "2026-07-13", "dayStatus": "NORMAL", "clockInTime": "09:00", "clockOutTime": null }] } }` |
| `GET /attendance/punch/records` | 今日打卡记录 | 缓存 30s，打卡后立即失效 | `{ "code": 0, "data": { "list": [{ "employeeName": "张三", "departmentName": "技术部", "punchDate": "2026-07-13", "clockInTime": "09:00", "clockInStatus": "NORMAL", "clockOutTime": null, "clockOutStatus": null, "source": "WEB" }], "total": 1 } }` |
| `GET /attendance/punch-fix/quota` | 补卡剩余次数 | 弹窗打开时请求，关闭后丢弃 | `{ "code": 0, "data": { "remainingQuota": 1 } }` |
| `POST /profile/attendance/punch-fix` | 补卡 | 成功后失效记录 | `{ "code": 0, "data": { "id": 1, "status": "PENDING" } }` |

```typescript
export default function access(initialState) {
```

## 5.4 数据刷新策略

```typescript
const queryClient = useQueryClient();
// 打卡操作后刷新
queryClient.invalidateQueries(['attendance-records']);
queryClient.invalidateQueries(['attendance-calendar']);
// 请假提交后刷新
queryClient.invalidateQueries(['leave-applications']);
// 补卡操作后刷新
queryClient.invalidateQueries(['attendance-punch-fix']);
// 加班提交后刷新
queryClient.invalidateQueries(['overtime-applications']);
```
