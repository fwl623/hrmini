# 1. 产品概述

## 1.1 产品背景

**业务背景：** 公司人力资源管理依赖 Excel 和纸质流程，存在数据分散、算薪效率低、审批不透明等问题。本系统建立统一员工数字化档案，实现入转调离全流程线上化。

**开发背景：** 人员 D 负责薪资核算工资条模块（hrms-payroll），覆盖管理后台 6 个页面 + 员工门户 1 个页面。

**核心业务链路：**

```
账套配置 → 薪资档案 → 创建核算批次 → 异步计算 → 预览调整 → 审批 → 发放 → 工资条查看
                                              ↕
                                         异常检测(黄牌/红牌)
```

# 3. 功能性需求测试分析

## 3.1 薪资核算模块

### 3.1.1 核算批次状态机测试

```
draft → [开始计算] → calculating(MQ异步) → pending_confirm
  → [预览调整][提交审批] → approving → [审批通过] → approved
  → [发放确认] → distributed
  任一节点可驳回 → rejected → [修改后重提] → pending_confirm
```

| 场景 | 操作 | 期望状态 |
| --- | --- | --- |
| 创建批次 | POST /payroll/batches | draft |
| 开始计算 | POST calculate | draft → calculating |
| 计算完成（MQ）| 异步回调 | calculating → pending_confirm |
| 提交审批 | POST submit | pending_confirm → approving |
| 审批通过 | 审批回调 | approving → approved |
| 发放确认 | POST distribute | approved → distributed |
| 审批驳回 | 审批回调 | approving → rejected |
| 修改后重提 | POST submit | rejected → pending_confirm |
| 删除草稿批次 | DELETE | draft → 删除 |
| 重复开始计算 | POST calculate（calculating 状态）| 50002 拦截 |

### 3.1.2 分段计薪测试（核心，需重点覆盖）

```
边界点：{月初, 入职日, 离职日+1, 转正日, 调薪生效日, 月末+1}
```

| 场景 | 段数 | 说明 |
| --- | --- | --- |
| 全月在职无变动 | 1 段 | 普通员工整月正常 |
| 月中入职 | 2 段 | 7/15 入职，7/15~7/31 计薪 |
| 月中转正 | 2 段 | 7/20 转正，试用比例→100% |
| 月中调薪 | 2 段 | 7/15 调薪生效 |
| 月中离职 | 2 段 | last_work_day=7/20，结算至离职日 |
| 入职+转正同月 | 3 段 | 7/15 入职、7/25 转正 |
| 入职+调薪同月 | 3 段 | 7/10 入职、7/20 调薪 |
| 转正+调薪同月 | 3 段 | 7/15 转正、7/25 调薪 |
| 试用比例边界 | — | 比例 0.80 / 1.00 边界值 |
| 社保基数上下限 | — | 低于/高于当地最低/最高标准 |

### 3.1.3 异常检测规则测试

| 级别 | 条件 | 期望标记 | 是否阻断 |
| --- | --- | --- | --- |
| 黄牌 | 当月请假 > 15 天 | LEAVE_HIGH | ❌ |
| 黄牌 | 当月加班 > 50 小时 | OVERTIME_HIGH | ❌ |
| 红牌 | 较上月变动 > 30% | SALARY_CHANGE_HIGH | ❌ |
| 红牌 | 新员工无薪资档案 | NO_SALARY_PROFILE | ✅ 阻断 |

### 3.1.4 异步核算性能测试

| 场景 | 目标 | 监测点 |
| --- | --- | --- |
| 500 人全量核算 | < 30s | MQ 消费耗时、批量 INSERT 耗时 |
| 核算进度轮询 | progress 字段递增 | Redis 进度更新 |
| 异常员工跳过 | FAILED 状态记录 | 不影响批次整体完成 |

### 3.1.5 工资条二次验证测试

| 场景 | 期望 |
| --- | --- |
| 员工端首次查看 → 弹验证框 → 输入正确密码 | 通过 → 展示明细 |
| 员工端首次查看 → 验证码错误 | 提示错误 → 可重试 |
| HR/财务端查看他人工资条 | 无需二次验证（角色权限即可）|
| 验证通过 30min 内再次查看 | 免验证（Redis TTL）|
| 验证通过超过 30min 后查看 | 需重新验证 |
| 批次未≥APPROVED 查看 | 50005 不可查看 |

### 3.1.6 老板审批条件测试（AD-07）

| 单人调薪比例 > 40% | #maxSingleAdjustRatio > 0.40 | 单人调薪占比 41% |
