# 1. 产品概述

## 1.1 产品背景

**业务背景：** 公司人力资源管理依赖 Excel 和纸质流程，存在数据分散、算薪效率低、审批不透明等问题。本系统建立统一员工数字化档案，实现入转调离全流程线上化。

**开发背景：** 人员 D 负责考勤请假加班模块（hrms-attendance），覆盖管理后台 8 个页面 + 员工门户 3 个页面。

**核心业务链路：**

```
考勤组配置 → 打卡/补卡 → 日汇总 → 月汇总(锁定) → 月度算薪 → 工资条
                         ↕
                  请假/加班审批通过
                  影响日汇总状态
```

# 3. 功能性需求测试分析

## 3.1 考勤管理模块

### 3.1.1 打卡判定测试（核心，6 种场景 × 上下班）

| 场景 | 上班打卡时间 | 期望状态 |
| --- | --- | --- |
| 正常上班 | ≤ onDuty | NORMAL |
| 迟到 | (onDuty, onDuty+lateThreshold] | LATE |
| 旷工半天 | > onDuty+lateThreshold | ABSENT_HALF |
| 重复打卡 | 同一天同一类型第二次 | 幂等拦截 |
| GPS 越界 | 配置了 GPS 范围但不在范围内 | 40004 |
| 非工作日打卡 | 节假日打卡 | 记录但不参与考勤判定 |

| 场景 | 下班打卡时间 | 期望状态 |
| --- | --- | --- |
| 正常下班 | ≥ offDuty | NORMAL |
| 早退 | [offDuty-earlyLeaveThreshold, offDuty) | EARLY_LEAVE |
| 旷工半天 | < offDuty-earlyLeaveThreshold | ABSENT_HALF |

### 3.1.2 日终缺卡判定测试

| 上班卡 | 下班卡 | 期望 day_status |
| --- | --- | --- |
| ✅ | ✅ | NORMAL/LATE 等 |
| ❌ | ✅ | MISSING_IN |
| ✅ | ❌ | MISSING_OUT |
| ❌ | ❌（且为工作日）| ABSENT |
| ❌ | ❌（但为节假日）| 不生成记录 |

## 3.2 请假管理模块

### 3.2.1 请假类型 × 审批链覆盖

| 请假类型 | 天数 | 审批规则 | 期望审批节点数 |
| --- | --- | --- | --- |
| 年假 | ≤3 天 | 直接上级 | 1 |
| 年假 | >3 天 | 直接上级 → 部门负责人 | 2 |
| 病假 | ≤1 天 | 直接上级 | 1 |
| 病假 | >1 天 | 直接上级 → 部门负责人 | 2（且附件必填）|

### 3.2.2 年假计算测试

| 工龄 | 期望年假天数 |
| --- | --- |
| < 1 年 | 0（首年按比例折算）|
| 1~10 年 | 5 |
| 10~20 年 | 10 |
| ≥ 20 年 | 15 |

### 3.2.3 calc-days 天数计算测试

| 场景 | 说明 |
| --- | --- |
| 周一至周五请假 3 天 | 排除周末 → 3 天 |

| 请假含法定节假日 | 排除节假日 → 实际天数减少 |
| 上午请假 0.5 天 | 返回 0.5 |
