# 员工档案 + 个人中心 · 建表脚本

| 项 | 内容 |
| --- | --- |
| 来源 | `hrms-employee-后端系分.md` **v1.3.0**（对齐总系分 v2.0.0） |
| 模块 | `hrms-employee`（员工档案 §4 + 个人中心档案 §9.1 / 手机号变更） |
| 字符集 | `utf8mb4` |
| 说明 | 本模块自建表如下；文末列出依赖的其他模块表（不在此脚本建表） |

个人中心说明：除手机号变更申请表外，档案查看/编辑复用员工档案表，不另建业务表；登录日志、操作审计、密码字段走账号/公共模块表。

---

## 一、本模块建表脚本

### 1. 员工主表 `employee`

```sql
CREATE TABLE IF NOT EXISTS `employee` (
    `id`                  BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT COMMENT '主键ID（作 employee_id 业务主键使用，永不复用）',
    `employee_no`         VARCHAR(16)       NOT NULL COMMENT '工号，格式：年份(4位)+部门编码(2位)+序号(3位)，如202401005',
    `user_id`             BIGINT UNSIGNED   NULL     COMMENT '系统账号ID，关联 sys_user.id',
    `name`                VARCHAR(32)       NOT NULL COMMENT '姓名',
    `gender`              VARCHAR(8)        NOT NULL COMMENT '性别：MALE/FEMALE',
    `mobile`              VARCHAR(16)       NOT NULL COMMENT '手机号（登录账号）',
    `email`               VARCHAR(128)      NOT NULL COMMENT '邮箱',
    `department_id`       BIGINT UNSIGNED   NOT NULL COMMENT '所属部门ID，关联 department.id',
    `position_id`         BIGINT UNSIGNED   NOT NULL COMMENT '职位ID，关联 position.id',
    `grade`               VARCHAR(8)        NULL     COMMENT '职级，如P5、M2',
    `manager_id`          BIGINT UNSIGNED   NULL     COMMENT '直属上级ID，关联 employee.id',
    `work_location`       VARCHAR(128)      NULL     COMMENT '工作地点',
    `hire_date`           DATE              NOT NULL COMMENT '入职日期',
    `employment_type`     VARCHAR(16)       NOT NULL COMMENT '用工类型：fulltime/parttime/intern',
    `employment_status`   TINYINT           NOT NULL COMMENT '在职状态：10=试用期 20=正式 30=待离职 40=已离职',
    `deleted`             TINYINT UNSIGNED  NOT NULL DEFAULT 0 COMMENT '逻辑删除：0=否 1=是',
    `created_at`          DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`          DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_employee_no` (`employee_no`),
    UNIQUE KEY `uk_mobile` (`mobile`),
    KEY `idx_dept_status` (`department_id`, `employment_status`),
    KEY `idx_hire_date` (`hire_date`),
    KEY `idx_name` (`name`)
) DEFAULT CHARACTER SET = utf8mb4 COMMENT = '员工主表';
```

### 2. 员工个人信息表 `employee_personal`

```sql
CREATE TABLE IF NOT EXISTS `employee_personal` (
    `employee_id`         BIGINT UNSIGNED   NOT NULL COMMENT '员工ID，关联 employee.id，主键',
    `id_number_enc`       VARCHAR(256)      NOT NULL COMMENT '身份证号密文（AES-256-GCM）',
    `id_number_hash`      VARCHAR(64)       NOT NULL COMMENT '身份证号SHA-256哈希（精确检索用）',
    `birthday`            DATE              NULL     COMMENT '生日',
    `household_address`   VARCHAR(256)      NULL     COMMENT '户籍地址',
    `residence_address`   VARCHAR(256)      NULL     COMMENT '现居住地址',
    `emergency_contact`   VARCHAR(64)       NULL     COMMENT '紧急联系人',
    `emergency_phone`     VARCHAR(16)       NULL     COMMENT '紧急联系电话',
    `created_at`          DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`          DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`employee_id`),
    KEY `idx_id_number_hash` (`id_number_hash`)
) DEFAULT CHARACTER SET = utf8mb4 COMMENT = '员工个人信息表（含敏感加密字段）';
```

### 3. 员工合同表 `employee_contract`

```sql
CREATE TABLE IF NOT EXISTS `employee_contract` (
    `id`                      BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `employee_id`             BIGINT UNSIGNED   NOT NULL COMMENT '员工ID，关联employee.id',
    `contract_type`           VARCHAR(16)       NOT NULL COMMENT '合同类型：FIXED=固定期限 UNFIXED=无固定期限 LABOR=劳务合同',
    `contract_expire_date`    DATE              NULL     COMMENT '合同到期日，固定期限合同必填',
    `probation_salary_ratio`  DECIMAL(5,4)      NOT NULL COMMENT '试用期待遇比例，范围0.80~1.00',
    `scheme_id`               BIGINT UNSIGNED   NOT NULL COMMENT '薪资账套ID，关联payroll_scheme.id',
    `base_salary`             DECIMAL(12,2)     NOT NULL COMMENT '基本工资',
    `created_at`              DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`              DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_employee` (`employee_id`)
) DEFAULT CHARACTER SET = utf8mb4 COMMENT = '员工合同表';
```

### 4. 员工银行卡信息表 `employee_bank`

```sql
CREATE TABLE IF NOT EXISTS `employee_bank` (
    `employee_id`         BIGINT UNSIGNED   NOT NULL COMMENT '员工ID，关联employee.id，主键',
    `bank_account_enc`    VARCHAR(256)      NULL     COMMENT '银行卡号密文（AES-256-GCM）',
    `bank_account_tail`   VARCHAR(4)        NULL     COMMENT '银行卡号后四位明文',
    `bank_name`           VARCHAR(64)       NULL     COMMENT '开户行',
    `created_at`          DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`          DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`employee_id`)
) DEFAULT CHARACTER SET = utf8mb4 COMMENT = '员工银行卡信息表';
```

### 5. 工号序列表 `employee_id_sequence_deprecated`

```sql
CREATE TABLE IF NOT EXISTS `employee_id_sequence_deprecated` (
    `id`            BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `year`          CHAR(4)           NOT NULL COMMENT '年份',
    `dept_code`     VARCHAR(8)        NOT NULL COMMENT '部门编码',
    `current_val`   INT               NOT NULL DEFAULT 0 COMMENT '当前序号',
    `created_at`    DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`    DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_year_dept` (`year`, `dept_code`)
) DEFAULT CHARACTER SET = utf8mb4 COMMENT = '工号序列表（Redis 降级兜底）';
```

> 工号优先 Redis Key `emp_no:{year}:{deptCode}` INCR；Redis 不可用时降级本表。

### 6. 工号复用历史表 `employee_no_history`

```sql
CREATE TABLE IF NOT EXISTS `employee_no_history` (
    `id`              BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `employee_no`     VARCHAR(16)       NOT NULL COMMENT '工号',
    `year`            CHAR(4)           NOT NULL COMMENT '年份',
    `dept_code`       VARCHAR(8)        NOT NULL COMMENT '部门编码',
    `employee_id`     BIGINT UNSIGNED   NULL     COMMENT '占用该工号的员工id，离职后置空',
    `reuse_flag`      TINYINT UNSIGNED  NOT NULL DEFAULT 0 COMMENT '0=占用中 1=可复用',

    PRIMARY KEY (`id`),

```

### 7. 员工薪资档案表 `employee_salary_profile`

```sql
CREATE TABLE IF NOT EXISTS `employee_salary_profile` (
    `id`                      BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `employee_id`             BIGINT UNSIGNED   NOT NULL COMMENT '员工ID，关联employee.id',
    `scheme_id`               BIGINT UNSIGNED   NOT NULL COMMENT '薪资账套ID，关联payroll_scheme.id（与employee_contract.scheme_id一致）',

    `performance_base`        DECIMAL(12,2)     NULL     COMMENT '绩效基数',
    `probation_ratio`         DECIMAL(5,4)      NOT NULL DEFAULT 1.0000 COMMENT '试用期待遇比例',
    `effective_date`          DATE              NOT NULL COMMENT '生效日期',
    `created_at`              DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',

    PRIMARY KEY (`id`),
```

### 8. 调薪历史表 `employee_salary_history`

```sql
CREATE TABLE IF NOT EXISTS `employee_salary_history` (
```

### 9. 调岗历史表 `employee_transfer_history`

```sql
CREATE TABLE IF NOT EXISTS `employee_transfer_history` (
    `id`                  BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT COMMENT '主键ID',
```

### 10. 手机号变更申请表 `employee_mobile_change_application`（个人中心）

```sql
CREATE TABLE IF NOT EXISTS `employee_mobile_change_application` (
    `id`              BIGINT UNSIGNED   NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `instance_id`     BIGINT UNSIGNED   NULL     COMMENT '审批实例ID，关联approval_instance.id',
    `employee_id`     BIGINT UNSIGNED   NOT NULL COMMENT '员工ID，关联employee.id',
    `user_id`         BIGINT UNSIGNED   NOT NULL COMMENT '系统用户ID，关联sys_user.id',
    `old_mobile`      VARCHAR(16)       NOT NULL COMMENT '旧手机号',
    `new_mobile`      VARCHAR(16)       NOT NULL COMMENT '新手机号',
    `sms_verified`    TINYINT UNSIGNED  NOT NULL DEFAULT 0 COMMENT '提交前已验证新号：0=否 1=是',
    `reason`          VARCHAR(256)      NULL     COMMENT '变更原因',
    `status`          VARCHAR(16)       NOT NULL COMMENT '申请状态：PENDING=审批中 APPROVED=已通过 REJECTED=已驳回 CANCELLED=已撤销',
    `created_at`      DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`      DATETIME          NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    KEY `idx_employee` (`employee_id`),
    KEY `idx_status` (`status`)
) DEFAULT CHARACTER SET = utf8mb4 COMMENT = '手机号变更申请表';
```

## 二、本模块表清单

| # | 表名 | 归属 | 说明 |
| ---: | --- | --- | --- |
| 1 | `employee` | 员工档案 | 主表 |
| 2 | `employee_personal` | 员工档案 | 个人信息 / 敏感字段 |
| 3 | `employee_contract` | 员工档案 | 合同与入职薪资配置 |
| 4 | `employee_bank` | 员工档案 | 银行卡 |
| 5 | `employee_id_sequence_deprecated` | 员工档案 | 工号序列降级 |
| 6 | `employee_no_history` | 员工档案 | 工号复用 |
| 7 | `employee_salary_profile` | 员工档案 | 薪资档案（算薪参数） |
| 8 | `employee_salary_history` | 员工档案 | 调薪历史 |
| 9 | `employee_transfer_history` | 员工档案 | 调岗历史 |
| 10 | `employee_mobile_change_application` | 个人中心 | 手机号变更申请 |

不建表：`employee_change_log`（已废弃，审计走 `operation_log`）。

建议建表顺序：先 `employee`，再其余以 `employee_id` 为关联的扩展表。

## 三、依赖的其他模块表

以下表**不由本模块建表**，须由对应模块先行建好（逻辑关联，DDL 中未强制物理外键）。

| 表名 | 所属模块 | 本模块依赖用途 |
| --- | --- | --- |
| `department` | 组织架构（hrms-org） | `employee.department_id`、调岗历史部门字段；工号取部门编码 |
| `position` | 组织架构（hrms-org） | `employee.position_id`、调岗历史职位字段 |
| `sys_user` | 权限账号（hrms-auth） | `employee.user_id` 绑定；创建登录账号；手机号变更后同步 `username`；`password_changed_at` |
| `login_log` | 权限账号（hrms-auth） | 个人中心 `GET /profile/security/login-logs` |
| `approval_instance` | 审批中心（hrms-approval） | `employee_mobile_change_application.instance_id`；入职/调岗等流程回调 |
| `onboarding_application` | 入转调离 | 入职申请审批通过后触发建档 |
| `transfer_application` | 入转调离 | `employee_transfer_history.transfer_app_id` |
| `payroll_scheme` | 薪资（hrms-payroll） | `employee_contract.scheme_id`、`employee_salary_profile.scheme_id` |
| `operation_log` | 公共（hrms-common） | 档案编辑/敏感字段查看审计 |
| `attendance_group_member` | 考勤（hrms-attendance） | 入职 MQ 消费侧写入（本模块只发事件） |

### 依赖关系简图

```plain
department / position          (组织架构)
        │
        ▼
    employee ─┬─ employee_personal
              ├─ employee_contract ──────► payroll_scheme
              ├─ employee_bank
              ├─ employee_salary_profile ► payroll_scheme
              ├─ employee_salary_history
              ├─ employee_transfer_history ► transfer_application / department / position
              └─ employee_mobile_change_application ► approval_instance / sys_user
        │
        ├─► sys_user / login_log          (权限账号)
        ├─► operation_log                 (公共审计)
        └─ MQ ► attendance_group_member   (考勤)

employee_id_sequence_deprecated / employee_no_history  （工号生成）
```
