# HRMS 工资条查询与薪资可见性说明（演示制度）

> 供助理小R知识库使用。注意：小R不得直接播报任何人工资数字。

## 一、员工如何查看本人工资条

1. 登录员工门户 →「我的工资条」。
2. 首次查看或会话过期后，需完成**二次验证**（验证登录密码）。
3. 验证通过后，在有效期内可查看明细；超时需再次验证。
4. 也可问小R「怎么查我的工资」，跳转到工资条页面——**金额仍须本人验证后在页面查看**。

## 二、为什么要二次验证

工资条属于高敏感信息。即使已登录系统，查看明细仍要求再次确认身份，降低共用电脑、会话未退出等场景下的泄露风险。

## 三、谁能看薪资全量（管理端）

| 角色倾向 | 能否看管理端薪资全量（账套/核算等） |
|----------|--------------------------------------|
| HR 专员 / 财务 | 可以（在权限范围内） |
| 系统管理员 | **不可以**（PRD 强制：菜单 + API 双拦截） |
| 普通员工 | 仅本人工资条 |
| 部门主管 | 一般不开放公司薪资全量；以权限配置为准 |

「系统管理员权限很大，但看不见薪资全量」是产品规则，不是漏配。

## 四、算薪与工资条出现的时间关系

1. 日常：打卡、请假、加班审批完成。
2. HR：**锁定月考勤**。
3. HR/财务：创建核算批次 → 异步计算 → 确认 → 审批 → 发放。
4. 发放后，员工才能在门户看到对应账期工资条。

加班费来自加班台账 × 账套倍率，不是加班单一通过就立刻出现在工资里。

## 五、小R 的红线

- 小R **不会**在聊天中直接报出工资、奖金、个税等金额。
- 问「我工资多少」时，应引导去门户工资条并完成二次验证。
- 问「公司全员薪资」时，无权限角色会被拒绝；系统管理员同样不能通过 AI 绕过。

## 六、常见问题

**问：本月加班了为什么工资条还没有加班费？**  
答：需等待考勤锁定与薪资批次发放完成。

**问：验证密码错了怎么办？**  
答：使用登录密码重试；多次失败可能导致安全限制，请稍后或联系管理员。

**问：财务能否让小R列出花名册顺便看薪？**  
答：财务族通常不能查花名册；薪资与花名册权限分离，AI 同步门控。
