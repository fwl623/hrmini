# HRMS 手机号变更与个人信息制度（演示制度）

> 供助理小R知识库使用。手机号即登录名，变更必须走审批。

## 一、为什么手机号不能直接改

在本系统中，**手机号通常同时作为登录用户名**。若允许在编辑页随意修改：

- 审计链路断裂（谁在何时改了登录凭据说不清）
- 可能造成账号冒用或通知送达失败

因此产品强制：**手机号变更必须走申请 → 审批/HR 处理 → 同步档案与登录名**。

## 二、员工如何申请改手机号

1. 登录员工门户 → 个人中心 / 账号安全相关入口。
2. 发起「手机号变更申请」，填写新手机号并完成短信等校验（以页面为准）。
3. 申请进入待办；HR 或审批人处理。
4. 通过后：更新员工档案手机号，并同步认证账号用户名。
5. 下次请用**新手机号**登录。

可对小R说明诉求，由小R引导到对应页面；真正提交仍走原业务接口。

## 三、员工可以自己改什么

门户个人资料遵循**白名单字段**，仅本人可改允许的非敏感项（如部分联系邮箱、基础展示信息等，以页面可编辑项为准）。

不可自助直改的典型项：

- 手机号（走变更审批）
- 部门、职位（走调岗）
- 身份证号、银行卡等敏感字段（HR 侧敏感查看与合规变更）

## 四、敏感信息查看

- 列表与详情默认**脱敏**展示（如身份证掩码）。
- 有权限人员查看明文时，需**二次验证**（输入登录密码等），并记审计日志。
- 系统管理员对薪资全量另有双拦截，与本条敏感查看相互独立。

## 五、常见问题

**问：管理端编辑员工时手机号灰掉了？**  
答：设计如此。请走手机号变更流程，不要绕过。

**问：换号后旧号还能登录吗？**  
答：同步完成后应以新手机号为准；旧号一般不再作为登录名。

**问：改邮箱要审批吗？**  
答：一般门户允许的自助字段可直接保存；手机号例外。
