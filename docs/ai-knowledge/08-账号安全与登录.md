# HRMS 账号安全与登录说明（演示制度）

> 供助理小R知识库使用。含登录加密、锁定、改密与会话超时。

## 一、如何登录

- 默认使用**手机号（登录名）+ 密码**登录。
- 管理端用户与门户员工共用认证体系，登录后按角色进入 `/admin` 或 `/portal`。
- 浏览器 Network 中密码以**密文**传输：前端使用服务端 RSA 公钥加密后再提交，服务端解密后与库内 BCrypt 哈希校验。

## 二、登录失败锁定

- 连续登录失败达到上限（演示：**5 次**）将锁定一段时间（演示：**15 分钟**）。
- 锁定期间即使密码正确也无法登录，请等待解锁或联系管理员。

## 三、密码策略

- 密码需满足复杂度（至少 8 位，含大小写字母与数字等，以系统校验为准）。
- **首次登录 / 长期未改密（如超过 90 天）** 可能强制修改密码；强制改密期间仅允许改密、查看资料、登出。
- 修改密码成功后，当前会话失效，需重新登录。

## 四、会话安全

- 登录成功签发 Access Token 与 Refresh Token。
- **约 30 分钟无操作**可能超时，需重新登录。
- 主动登出后，Token 进入黑名单，无法继续访问。

## 五、常见问题

**问：提示账号锁定怎么办？**  
答：等待锁定时间结束，或由管理员协助处理；勿高频重试。

**问：为什么必须改密码才能进系统？**  
答：首次或密码过期策略，保障账号安全。

**问：小R能帮我改密码吗？**  
答：请到门户账号安全或强制改密弹窗操作；小R可指引入口，不能代替验证旧密码。
