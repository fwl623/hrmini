# HRMS 加班与调休管理制度（演示制度）

> 供助理小R知识库使用，与系统加班台账、审批、算薪倍率一致。

## 一、加班申请原则

员工因工作需要延长工作时间，须事先或按公司要求事后补办加班申请，经审批通过后计入**加班台账**。未审批通过的加班，**不计入**加班费与调休。

## 二、如何申请

1. 门户「加班」页面，或对小R说「我要申请加班」。
2. 填写加班日期、起止时段、事由。
3. 提交后进入审批流。时长偏长时可能触发 **HR 二审**。
4. 审批通过后写入加班台账；可按规则折算调休余额。

## 三、加班倍率（算薪口径）

算薪从加班台账取数，常见倍率：

| 日期类型 | 倍率 | 说明 |
|----------|------|------|
| 工作日延长 | 1.5 | 平时加班 |
| 休息日 | 2.0 | 周末等休息日 |
| 法定节假日 | 3.0 | 法定假日加班 |

加班费示意公式（演示账套口径）：

> （月基本工资 ÷ 21.75 ÷ 8）× 倍率 × 加班小时数

实际以公司启用账套配置为准。

## 四、加班与调休的换算

- 审批通过的加班时长，可按 **8 小时 = 1 天** 折入调休（COMP_OFF）。
- 调休有过期日，过期未用会清零，请及时安排调休请假。
- 选择「要调休」还是「要加班费」以公司政策与审批意见为准；系统侧以台账 + 账套公式消费。

## 五、加班不直接改工资

重要说明（常被问到）：

- 加班审批通过 **不会立刻改工资条**。
- 数据进入加班台账，待 HR **锁定月考勤** 并创建薪资核算批次后，由账套公式计算加班费。
- 因此月末前请确保加班单已审批完成。

## 六、常见问题

**问：周末加班一定按 2.0 算吗？**  
答：按加班日期是否落在休息日/法定假日判定；日历与节假日配置以系统为准。

**问：忘了申请可以补吗？**  
答：应尽快补提加班单并说明原因，仍须审批通过才能进台账。

**问：小R能直接帮我提交加班吗？**  
答：小R可以打开加班表单卡片，由你确认后提交；真正写库走原有加班 API 与审批，不是模型私自落库。
