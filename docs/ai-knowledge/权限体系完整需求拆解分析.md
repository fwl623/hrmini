1. # 人资管理系统 PRD 权限体系全量明细分析

   以下内容严格基于 PRD 原文推导，按**功能操作权限（能做 / 不能做）→ 行级数据范围（能看哪些人的数据）→ 字段级权限（同一条数据能看哪些列）**三层结构逐角色完整拆解，最后汇总 PRD 遗漏的权限缺口。

   ------

   ## 一、系统管理员

   ### 1. 功能操作权限

   #### ✅ 可执行操作

   - **系统底层配置**：角色新增 / 编辑 / 删除、权限分配、系统参数设置、数据备份与恢复、登录安全策略配置、操作 / 审计日志查看
   - **组织架构管理**：部门增删改查、职位增删改查、部门层级调整、部门负责人设置、排序序号调整
   - **数据查看类**：全量员工档案查看、全公司考勤数据查看、全公司所有审批单流程查看
   - **账号管理类**：员工账号启用 / 禁用、密码重置

   #### ❌ 不可执行操作

   - 所有人事业务操作：发起入职 / 转正 / 调岗 / 离职流程、编辑员工档案信息、处理员工人事异动
   - 所有薪资业务操作：薪资账套配置、员工薪资档案编辑、月度薪资核算、薪资审批、薪资报表导出
   - 业务审批操作：不能审批任何请假、离职、转正等业务单据，仅可查看流程进度
   - 考勤规则配置：无考勤组、班次、请假规则的编辑权限
   - 越权修改：不能篡改业务数据、审批记录

   ### 2. 行级数据可见范围

   #### ✅ 可见数据

   - 员工档案：全公司所有员工（试用期 / 正式 / 待离职 / 已离职）的基础档案列表
   - 组织架构：全公司完整部门树、职位体系、职级序列
   - 考勤数据：全公司所有员工的打卡记录、请假记录、考勤统计报表
   - 审批数据：全公司所有类型审批单、审批历史、审批流转记录
   - 系统数据：所有用户登录日志、操作审计日志、系统配置项

   #### ❌ 不可见数据

   - 所有薪资类数据：员工薪资明细、工资条、薪资核算批次、人力成本报表
   - 员工核心敏感字段：PRD 未明确授权，默认不可直接查看身份证号、银行卡号等隐私信息

   ### 3. 字段级权限

   PRD 未单独定义系统管理员的字段查看权限，仅明确**薪资全量数据不可见**；人事类敏感字段（身份证、紧急联系人等）的查看权限属于 PRD 遗漏项。

   ------

   ## 二、HR 专员

   ### 1. 功能操作权限

   #### ✅ 可执行操作

   - **组织架构模块**：查看全公司部门 / 职位 / 职级体系，可新增 / 编辑 / 删除部门与职位

   - **员工档案模块**：全量员工档案新增、编辑、查看；维护员工个人信息、工作信息、合同信息；员工离职后档案管理

   - 入转调离全流程

     ：

     - 发起入职 / 转正 / 调岗 / 离职申请，编辑草稿，撤回一级审批中的单据
     - 确认员工到岗入职、标记放弃入职、处理审批驳回后的重新发起
     - 跟进全公司所有异动流程进度

   - 考勤管理模块

     ：

     - 配置考勤组、班次规则、迟到早退阈值、工作日 / 节假日设置
     - 查看全公司考勤数据，处理异常考勤，查看部门 / 全公司考勤统计报表
     - 请假 / 加班 / 补卡流程备案、异常调整

   - 薪资管理模块

     ：

     - 配置薪资账套、工资项目、计算公式
     - 维护员工薪资档案、调薪记录、试用期薪资设置
     - 发起月度薪资核算、手动调整薪资明细、提交薪资审批、查看薪资报表

   - **审批管理模块**：查看全公司所有审批单、催办审批、转交审批流程

   #### ❌ 不可执行操作

   - 系统底层配置：角色权限管理、系统参数设置、数据备份、审计日志导出
   - 薪资最终审核：无薪资批次的最终审核权，仅可提交至财务审核
   - 越权操作：不能修改系统自动生成的工号、入职日期、系统状态等字段
   - 财务专属操作：不能导出财务口径的成本报表、不能标记薪资已发放

   ### 2. 行级数据可见范围

   #### ✅ 可见数据

   - 员工档案：全公司所有员工（在职 / 待离职 / 已离职）的完整档案
   - 薪资信息：全公司所有员工的薪资档案、薪资明细、核算批次、工资条、全维度薪资报表
   - 考勤数据：全公司所有员工的打卡、请假、加班、补卡记录，个人 / 部门 / 全公司考勤统计
   - 审批数据：全公司所有类型审批单的完整信息、审批历史、流转进度
   - 组织架构：全公司完整部门、职位、职级体系

   #### ❌ 不可见数据

   - 系统底层配置数据：权限配置细节、数据库备份文件、其他用户密码
   - 财务专属对账数据：银行发放明细、财务凭证数据

   ### 3. 字段级权限（员工档案）

   #### ✅ 全部字段可查看 + 可编辑（系统生成字段除外）

   - 基础信息：工号、账号、在职状态、入职日期（仅查看）
   - 个人信息：姓名、性别、手机号、邮箱、身份证号、生日、户籍 / 居住地址
   - 工作信息：部门、职位、职级、汇报人、工作地点、入职类型
   - 薪资合同：合同类型 / 到期日、薪资账套、基本工资、银行账号、开户行、试用期待遇比例

   ------

   ## 三、部门主管

   ### 1. 功能操作权限

   #### ✅ 可执行操作

   - **员工查看**：查看本部门及下属员工的档案信息、人员名单

   - 审批管理

     ：

     - 审批本部门下属的请假、补卡、入职、转正、离职申请
     - 审批调岗流程中本部门相关节点（原部门转出确认、新部门接收确认）
     - 支持审批转交、委托他人代审批

   - **考勤管理**：查看本部门员工考勤明细、部门考勤统计报表、出勤率 / 迟到率数据

   - **入职跟进**：查看本部门待入职人员、修改入职日期、标记放弃入职

   #### ❌ 不可执行操作

   - 员工档案编辑：不能修改任何员工（含下属）的档案信息
   - 流程发起：不能发起入职、转正、调岗、离职流程，仅可审批
   - 组织架构编辑：不能新增 / 修改 / 删除部门、职位、职级
   - 薪资相关操作：完全不能查看、编辑、审批任何薪资数据
   - 跨部门操作：不能查看、审批其他部门员工的任何单据与数据
   - 考勤规则配置：不能修改考勤组、班次、请假规则等系统配置

   ### 2. 行级数据可见范围

   #### ✅ 可见数据

   - 员工档案：本部门所有在职员工的基础档案列表与详情
   - 考勤数据：本部门员工的打卡记录、请假记录、加班记录、部门考勤统计报表
   - 审批数据：本部门员工发起的所有审批单、自己作为审批人的待办 / 已办单据
   - 组织架构：全公司部门架构树（仅可查看部门名称结构，不可查看其他部门员工详情）

   #### ❌ 不可见数据

   - 跨部门员工的所有数据：档案、考勤、审批、薪资
   - 所有薪资类数据：员工工资、薪资报表、核算批次
   - 员工敏感隐私字段：身份证、银行卡、紧急联系人、合同详情
   - 全公司级统计报表：总人数、全公司考勤汇总、人力总成本

   ### 3. 字段级权限（员工档案）

   #### ✅ 可见字段

   姓名、工号、部门、职位、职级、手机号、入职日期、在职状态、工作地点

   #### ❌ 不可见字段

   身份证号、薪资信息、紧急联系人、银行卡号、合同类型、合同到期日、银行开户行、社保公积金基数

   ------

   ## 四、财务专员

   ### 1. 功能操作权限

   #### ✅ 可执行操作

   - **薪资审核**：审核 HR 提交的月度薪资核算批次，可通过 / 驳回薪资申请
   - **报表查看**：查看人力成本报表、部门薪资分布、月度薪资趋势等财务维度报表
   - 本人个人中心所有操作：查看个人档案、考勤、工资条

   #### ❌ 不可执行操作

   - 所有人事业务：员工档案编辑、入转调离流程发起 / 审批、考勤管理
   - 薪资配置操作：不能修改薪资账套、不能编辑员工薪资档案、不能发起薪资核算
   - 组织架构管理：不能编辑 / 配置部门、职位
   - 非薪资类审批：不能查看、处理请假、离职、转正等任何人事审批单
   - 员工账号管理：不能禁用 / 重置员工账号

   ### 2. 行级数据可见范围

   #### ✅ 可见数据

   - 薪资数据：全公司所有员工的薪资明细、应发 / 实发金额、薪资构成、薪资核算批次数据
   - 成本报表：部门薪资成本汇总、月度薪资趋势、社保公积金汇总报表
   - 个人数据：本人的员工档案、考勤记录、工资条

   #### ❌ 不可见数据

   - 员工人事档案：除薪资字段外，员工的身份证、考勤、审批、合同、紧急联系人等所有人事信息
   - 非薪资类审批单据：请假、离职、转正、入职等所有人事审批流程
   - 组织架构详情：不能查看部门人员名单、员工基础档案
   - 考勤全量数据：所有员工的打卡、请假、加班记录

   ### 3. 字段级权限（薪资相关）

   #### ✅ 可见字段

   基本工资、绩效奖金、津贴、加班费、考勤扣款、社保公积金、个税、应发工资、实发工资

   #### ❌ 不可见字段

   员工身份证号、银行卡号、开户行、紧急联系人、合同信息、考勤明细、请假事由

   ------

   ## 五、普通员工

   ### 1. 功能操作权限

   #### ✅ 可执行操作

   - **个人档案**：查看个人完整档案；编辑可修改字段（邮箱、生日、现居住地址、紧急联系人）；提交手机号修改申请
   - **考勤相关**：网页打卡、查看个人考勤日历、发起请假申请、发起补卡申请、查看假期余额
   - **审批相关**：查看自己发起的所有审批单、审批进度；取消审批中的申请
   - **薪资相关**：查看个人历史工资条、个人薪资趋势图
   - **账号安全**：修改密码、绑定 / 解绑手机、查看个人登录日志

   #### ❌ 不可执行操作

   - 任何管理类操作：不能查看其他员工档案、不能审批任何单据、不能修改系统配置
   - 人事异动发起：不能直接发起转正、调岗、正式离职流程（PRD 规定离职由 HR 发起）
   - 薪资操作：不能查看他人工资、不能修改个人薪资档案
   - 考勤配置：不能修改考勤组、班次、请假规则
   - 跨数据查看：不能查看任何其他员工的业务数据

   ### 2. 行级数据可见范围

   #### ✅ 可见数据

   - 本人所有数据：个人档案、考勤记录、请假 / 补卡审批、工资条、薪资趋势
   - 公开组织架构：PRD 未明确授权通讯录，按权限表默认仅能查看本人数据，不可查看其他员工任何信息

   #### ❌ 不可见数据

   - 其他所有员工的档案、考勤、薪资、审批数据
   - 部门 / 全公司级统计报表
   - 所有后台管理配置功能、薪资账套规则、考勤规则配置

   ### 3. 字段级权限（员工档案）

   #### ✅ 本人数据：所有字段全部可见

   姓名、手机号、身份证号、薪资信息、紧急联系人、银行卡号、合同信息等全部个人字段

   #### ❌ 他人数据：无任何查看权限，不可见所有字段

   ## 六、PRD 权限体系遗漏 / 不明确点汇总

   ### 1. 角色维度缺失，权责边界模糊

   - **未区分 HR 专员与 HR 负责人**：审批流中多次出现「HR 负责人」审批节点（入职二审、转正终审、调岗备案、离职终审），但角色列表只有「HR 专员」，未定义两类 HR 的权限差异，会导致普通 HR 越权审批。
   - **缺少「直接上级」角色映射**：请假、补卡审批流明确「直接上级」为第一审批人，但角色体系只有「部门主管」。当员工直接上级不是部门负责人时，权限无法对应。
   - **缺少「高管 / 老板」角色**：薪资审批流包含可选的「老板审批」节点，但无对应角色与权限定义。

   ### 2. 核心业务流程权限缺失

   - **员工端离职申请流程空白**：5.4.1 提到「员工申请离职走另一个申请流程」，但全文未定义普通员工发起离职申请的入口、审批流、权限规则，仅定义了 HR 发起的离职审批，员工侧能力完全缺失。
   - **加班申请流程未定义**：考勤模块包含加班时长、调休转换，但未定义加班申请的发起权限、审批流、数据查看权限，属于核心流程遗漏。

   ### 3. 字段级权限覆盖不全

   - **系统管理员字段权限未定义**：未明确系统管理员能否查看员工身份证、银行卡等敏感字段，存在越权风险。
   - **财务专员字段权限不完整**：仅明确「基本工资」对财务可见，未说明绩效、津贴、社保、个税等其他薪资字段是否可见；银行卡号、开户行对财务是否可见未明确。
   - **缺少编辑权限细分**：2.3 仅定义了「查看」权限，未定义各角色的「编辑」权限边界，比如 HR 能否修改员工身份证号、普通员工能编辑哪些字段，仅在字段表零散标注，未统一收口。

   ### 4. 通用管理权限未明确

   - **数据导出权限完全缺失**：未定义各角色的数据导出权限，比如 HR 能否导出全量员工档案 / 薪资表、部门主管能否导出本部门考勤、财务能否导出成本报表，存在数据泄露风险。
   - **考勤配置权限归属不明**：考勤组、班次、节假日规则的增删改权限，未写入权限表，默认 HR 负责但无明文定义。
   - **审批流配置权限缺失**：审批流程、条件规则（如请假天数阈值）的配置权，未明确归系统管理员还是 HR。

   ### 5. 特殊场景权限空白

   - **已离职员工数据权限未定义**：仅提到「保留档案并脱敏」，但未明确哪些角色可查看已离职员工档案、能看到哪些字段、部门主管能否查看本部门历史离职人员。
   - **委托审批权限边界模糊**：未说明委托审批的范围限制（如能否跨部门委托、能否委托给普通员工），以及委托后数据权限是否同步放开。
   - **普通员工通讯录权限不明确**：按现有权限表普通员工看不到任何同事信息，不符合企业通讯录的常规需求，是否开放基础公开信息未定义。
   - **操作日志查看权限未细化**：仅提到审计日志，未明确谁能查看、能查看哪些范围的日志（如 HR 能否查看薪资操作日志）。
