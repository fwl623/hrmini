# 助理小R使用指南（演示制度）

> 本文档既可给用户看，也可入库供小R自洽回答「你能做什么」。

## 一、小R 是什么

小R 是 HRMS 内置助手，主要能力：

1. **制度问答**：基于公司上传的知识库（请假、加班、入职、工资条等）检索回答。
2. **办事引导**：识别请假、加班、待办、打卡、花名册等意图，给出跳转或表单/列表卡片。
3. **权限感知**：按你的角色显示能力；没权限的功能不会生成越权卡片。

## 二、推荐说法（更容易命中）

| 你想办的事 | 可以这样说 |
|------------|------------|
| 请假 | 我要请假 / 请年假 / 生病了 |
| 查假期余额 | 我的年假还剩几天 / 假期余额 / 调休还剩多少 |
| 加班 | 我要申请加班 |
| 打卡 | 怎么打卡 |
| 工资条 | 怎么查我的工资 |
| 待审批 | 我的待审批 / 今日待办 |
| 查人数 | 销售中心有多少人 / 各部门人数 |
| 查制度 | 年假怎么算 / 病假要不要证明 / 入职审批通过能否登录 |

## 三、小R 不会做的事

- 不会在聊天里直接报出工资、奖金等金额。
- 不会绕过审批替你「悄悄提交成功」。
- 不会给无权限角色打开薪资全量、花名册等受限能力。
- 不会代替本人完成打卡。

表单卡片需要你确认后才调用正式业务接口；审批、余额、DataScope 全部生效。

## 四、制度答不准时怎么办

- 知识库可能未收录或检索相似度不足；小R会少答或引导去页面/人工。
- HR 可在管理端「知识库管理」上传/启停制度文档后重新提问。
- 办事类问题即使模型繁忙，本地能力卡片仍可能可用。

## 五、角色差异简述

- **员工**：门户办事 + 查本人制度与工资条入口。
- **主管**：待办审批、本部门相关查询（在权限内）。
- **HR**：花名册、入转调离、考勤运营等（在权限内）。
- **财务**：薪资相关，通常不能查花名册。
- **系统管理员**：系统配置能力强，但**看不到薪资全量**，AI 同样拦截。
