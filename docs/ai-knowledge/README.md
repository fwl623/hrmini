# HRMS 知识库文档说明（给运营上传）

本目录文档用于喂给管理端 **AI 知识库**（助理小R RAG）。

## 上传步骤

1. 使用具备知识库管理权限的账号登录管理端。
2. 打开 **助理小R / 知识库管理**（路径以菜单为准，常见 `/admin/ai/knowledge`）。
3. 上传本目录下的 `.md` 文件（也支持 `.txt` / `.pdf`）。
4. 等待状态变为 **READY** 后再在聊天中提问验证。
5. 停用文档后检索会过滤；删除会清向量。

## 编写注意

- 尽量短段落、带小标题与「问/答」，便于分块检索（默认约 500 字一块）。
- 内容应与系统真实规则一致，避免「制度写一套、系统另一套」。
- 不要在知识库中写入真实员工薪资、身份证等敏感样例数据。
