# HRMS 审批中心使用说明（演示制度）

> 供助理小R知识库使用。覆盖待办审批与多类流程统一入口。

## 一、审批中心是什么

审批中心是统一待办台，汇聚多类流程任务，例如：

- 请假、加班、补卡
- 入职、转正、调岗、离职
- 手机号变更
- 薪资核算批次
- 其他接入同一引擎的流程

主管主要使用「待我审批」；HR 等角色还可管理入转调离等发起类功能（权限分离：`能审批` ≠ `能发起人事流程`）。

## 二、员工侧：我发起的申请

1. 在各业务页（请假/加班/离职等）提交后，可在审批中心查看进度。
2. 状态一般为：待审批 → 已通过 / 已驳回 / 已撤销等。
3. 可对小R说「看看审批进度」类问题，并跳转审批相关页面（以能力开放为准）。

## 三、主管侧：如何审批

1. 进入管理端「审批中心」，或对小R说「我的待审批」「今日待办」。
2. 小R可展示待办列表卡片，在卡片内通过/驳回（仍调用正式审批 API）。
3. 审批时请填写意见；驳回请假会导致年假/调休预扣余额归还。
4. 超时任务可能有 SLA 提醒/催办，请及时处理。

## 四、委托与催办（能力说明）

- 支持审批委托等机制时，被委托人按有效审批人处理待办。
- 催办用于提醒节点审批人，不改变业务状态机本身。
- 具体按钮以当前环境前端为准。

## 五、常见问题

**问：我是主管，为什么看不到入职管理菜单？**  
答：发起入转调离通常需要流程管理权限；主管默认侧重审批中心。

**问：点了同意没反应？**  
答：可能任务已被其他人处理或状态已变；刷新待办。重复提交会按冲突/幂等规则拒绝。

**问：小R 审批和页面审批一样吗？**  
答：一样。都走同一套审批引擎与权限校验，只是入口在聊天卡片。
