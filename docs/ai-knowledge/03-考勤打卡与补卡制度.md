# HRMS 考勤打卡与补卡制度（演示制度）

> 供助理小R知识库使用。对应门户打卡、考勤组班次判定、补卡审批与月锁定。

## 一、日常打卡

- 员工每天一般打两次卡：**上班（IN）** 与 **下班（OUT）**。
- 打卡结果按所属**考勤组班次**自动判定，不是只记时间戳。

常见判定状态：

| 状态 | 含义 |
|------|------|
| NORMAL | 正常 |
| LATE | 迟到（超过上班点 + 宽限，默认约 15 分钟） |
| EARLY_LEAVE | 早退 |
| ABSENT | 旷工（偏差过大） |
| MISSING_IN / MISSING_OUT | 缺上班卡 / 缺下班卡 |
| LEAVE | 当天有已通过请假，按请假处理 |

班次类型含固定班（FIXED）、弹性班（FLEXIBLE）等；具体上下班时刻以个人考勤组为准。

## 二、幂等与连点

系统对「同一员工、同一天、同一类型」打卡做防重复处理。请勿连续猛点；若提示已打卡，以系统记录为准。

## 三、补卡规则

- 漏打卡可发起**补卡申请**，须走审批（通常上级，必要时 HR）。
- **每月补卡次数有限（演示环境为 2 次）**，请珍惜额度。
- 当日考勤已正常时，不可再对该日滥补。
- 补卡通过后参与日/月汇总；**月考勤锁定后不可再改**。

## 四、日汇总与月汇总

- 系统定时（如每日凌晨）将打卡流水聚合成日汇总。
- 日汇总采用上下午双槽位记录正常/迟到/早退/旷工/请假/缺卡等。
- 月汇总累计应出勤、实际出勤、迟到早退、请假、加班等，供算薪使用。

## 五、月考勤锁定（重要）

- HR 锁定某月考勤后，该月打卡与相关考勤数据冻结。
- **未锁定的月份不能进行该月薪资核算**——考勤锁是算薪闸门。
- 员工如发现异常，须在锁定前通过补卡/请假/加班流程修正。

## 六、员工操作指引

1. 门户「考勤打卡」完成上下班打卡；也可问小R「怎么打卡」跳转页面。
2. 异常缺卡：走补卡或联系主管说明。
3. 请假日一般无需再纠结打卡状态，以已通过请假为准。
4. 查看个人考勤汇总以门户/管理端展示为准。

## 七、常见问题

**问：迟到怎么算？**  
答：超过考勤组上班时间加上宽限阈值记为 LATE，具体分钟以考勤组配置为准。

**问：一整天没打卡但是请了假？**  
答：若请假已审批通过，日汇总可按请假处理，避免记成旷工。

**问：小R能替我打卡吗？**  
答：不能。打卡必须本人在门户操作，小R只提供指引与跳转。
